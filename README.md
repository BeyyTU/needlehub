# Beyy Hub — Crack the Geode!

Native Roblox menu with collection, camp, egg and GEO-MAG upgrade automation.

## Load

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/BeyyTU/needlehub/geode-mirror/loader-beyy.lua?refresh=" .. tostring(os.time())))()
```

**BeyyHub UI cleanup (v1.10.34):** The Main tab now emphasizes Auto Farm Escapes, collection, Crack & Sell, Auto Escape, and GEO-MAG upgrades. Optional speed, repeat, pickup-range, Overcharge and boss/perk tuning controls are inside collapsed **Advanced** groups; expanding a group does not reset its settings. Right Ctrl opens/closes the menu. Startup automatically restores the saved default config, including its enabled automation. With no saved config, automation starts off. A queued teleport reload restores the enabled options from the preceding session instead of the config's automation toggles.

Use **Save Config** after changing settings. **Auto-load Saved Config** defaults on; turn it off and save to disable restoration on future manual loads. Older saved configs automatically migrate to this behavior. Repeated or concurrent loaders reuse the active menu.

A local cached copy can also be loaded:

```lua
loadstring(readfile("GeodeHub/loader.lua"))()
```

## Fix anti-cheat recorder zero-sample bug — v1.10.85

A user-submitted `Geode/anticheat_client_diagnostics.json` from **v1.10.83** contained `CapturedSamples: 0`, an empty sample array, 952 reported "persistence failures", and 131 successful file saves. Code inspection identified the root cause: the movement diagnostics module attempted `State.run("Phase")` and `State.run("Mode")` without importing the game's native State module into its own lexical scope. Sampling therefore failed immediately on each attempt. The file's old `PersistenceFailures` counter also incorrectly included *sampling* failures, so those 952 reports were **not** proof of any anti-cheat event or failed file write.

This release imports the State module in the recorder's own scope via a protected require and reads mode/phase through a guarded helper. It also tracks `SamplingFailures` and `PersistenceFailures` separately, includes `LastSamplingError` and `LastPersistenceError` in saved JSON, preserves `RootCanCollide=false` correctly, and shows sample/file error counts and the latest sampling error in Status & Logs.

**Test:** Load the new version, enable `Record Pre-Kick Movement (Opt-in)`, and check that `Samples` increases in **Status & Logs** before testing Auto Endless again. Then retrieve `Geode/anticheat_client_diagnostics.json`. Sampling still requires live-game validation. This change affects reporting only; v1.10.84 smooth circular flight, the 16-stud/second flight setting, native WalkSpeed monitoring, and other features remain unchanged.

## Client movement / anti-cheat diagnostics — v1.10.83

The game server's private anti-cheat telemetry, detection logic, server-stored logs and original disconnect verdicts **cannot be read from a normal client script**. This feature is a **client-side observational recorder**, not a server anti-cheat dump and does not disable or alter any anti-cheat.

**Use:** Open BeyyHub → **Status & Logs** → **Anti-Cheat / Movement Diagnostics (Client Only)** → enable `Record Pre-Kick Movement (Opt-in)` **before** reproducing a movement disconnect. While enabled, the recorder samples the local character every ~0.08 seconds and saves a rolling snapshot to `Geode/anticheat_client_diagnostics.json` about every 0.6 seconds. The snapshot is overwritten with the latest ~360 samples (~30 seconds), up to 150 recent state changes/anomalies, and up to 80 matching client-output log messages. An abrupt disconnect can happen before the next save; the file may not contain the exact final frame or server's kick text. Recorder is **off by default** and does not automatically resume after a server teleport.

You may instead press `Export Client Anti-Cheat Dump Now` for a snapshot, or choose **Anti-Cheat / Movement** under Debug Focus and press **Export Debug Diagnostics**. Disabling/unloading the opt-in recorder saves a final snapshot and disconnects its output/Heartbeat listeners.

**Captured fields** include local and approximated server timestamps; phase/mode; character/root presence and 3D position; intersample displacement and computed horizontal/3D speed; native `Humanoid.WalkSpeed`; root linear/angular velocity; humanoid state, floor material and movement locks; flight command, fly/noclip state, and Endless/Win Farm states; movement-anomaly events and selected local-output messages; and a list of potentially relevant *visible client-side* script/remote paths. The anomaly labels are heuristic observations, **not** evidence of the game's server rules or what caused a kick. No network hooks or server commands are used. This does not automatically collect logs from other users or private server data.

**Important:** The user-requested Auto Endless Fly + Noclip controller remains at 16 studs/second by default, and v1.10.82's read-only walking-speed monitor remains unchanged. This release only adds diagnostics. No live Roblox test was performed.

### GEO-MAG perk priorities

**Adaptive timed ranking is the default (v1.10.35)** when the separate Auto Select Perk toggle is enabled; it dynamically weights boss damage, mine-clear rate, lantern runway and measured recent boss timing. The following static ordering describes the optional legacy balanced mode, not the new adaptive ranking. These are heuristic priorities for reaching more Endless depths, rather than a guaranteed optimum. Shortcut, recurring Oil Flask sustain, Eternal Flame and Wide Sweep are high priorities. Pile damage, Chain Reaction and boss damage follow, with rarity/stack count and existing modifiers affecting their order. Emergency oil takes priority when less than a minute of effective burn time remains. Extra recurring oil is downgraded when the existing income covers the recently measured depth pace.

Speed perks use the active firing path's estimated timing floor: measured frame timing during Auto Endless native held fire, or the direct pickup loop's 50 ms floor otherwise. Bag perks are downgraded with unlimited capacity. Crack-power bonuses are evaluated through the boss damage square-root curve. Cash/value is more useful before GEO-MAG upgrades are maxed. Ability duration, cooldown, size and damage perks gain priority when automatic Overcharge is unlocked and active; ability cooldown perks are downgraded at the configured cooldown minimum. The ranking export includes the current order and the actual reasoning for each offered card.

The native selection path was checked live: an Epic Tempered card was selected over Gem Finder and Bottomless Luck and confirmed by the server. No rerolls were used.

The whole-pile scan measured five contour radii of approximately 33.5, 28.0, 21.9, 15.6 and 9.8 studs. Auto Endless now uses only the bottom contour (about 33.5 studs in that snapshot). Radius varies with angle, depth shape and depletion. The character path sits above the fitted slice by the configured hover clearance. Geometry tests covered all 1,577 columns in a live snapshot, with 13,387 generated blueprint cell locations and 3,785 deduplicated visible targets. Blueprint positions include already-mined cells; runtime planning uses remaining stack counts.

## Passive transition recorder

A separate observer records PlaceId, JobId, OnTeleport events, phase/run-start changes, and queued arrivals. It makes no gameplay requests.

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/sceneton/geode/main/transition-recorder.lua?refresh=" .. tostring(os.time())))()
```

Logs: `Geode/transition_events.jsonl` and `Geode/transition_latest.json`.

Stop it with:

```lua
getgenv().GeodeTransitionRecorder.Stop()
```

A changed JobId establishes a server change. A changed RunStart in the same surviving observer/job indicates an in-server run reset. Compare the actual Play Again transition; a custom loading screen alone does not distinguish the two.
