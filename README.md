# Beyy Hub — Crack the Geode!

Native Roblox menu with collection, camp, egg and GEO-MAG upgrade automation.

## Load

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/sceneton/geode/main/loader.lua?refresh=" .. tostring(os.time())))()
```

Right Ctrl opens/closes the menu. Startup automatically restores the saved default config, including its enabled automation. With no saved config, automation starts off. A queued teleport reload restores the enabled options from the preceding session instead of the config's automation toggles.

Use **Save Config** after changing settings. **Auto-load Saved Config** defaults on; turn it off and save to disable restoration on future manual loads. Older saved configs automatically migrate to this behavior. Repeated or concurrent loaders reuse the active menu.

A local cached copy can also be loaded:

```lua
loadstring(readfile("GeodeHub/loader.lua"))()
```

## Features

- **Auto Endless Mode:** follows a circular bottom orbit, offset 1.5 studs farther out (2.5 studs inward from the previous orbit). Radius, height and camera standoff stay fixed for the whole depth, and the character stays level while firing. Mining uses a steady inward lower-pile aim with the existing 10-degree offset; it does not select or track individual geodes. Boss targeting keeps its own aim. Each full 360-degree lap targets **approximately 2.8 uninterrupted seconds (5× the original 14-second speed)**. Mining camera smoothing and its maximum turn rate are scaled 5× to keep the inward aim aligned with the faster movement; the orbit's radius, height, and boss-targeting behavior are unchanged. The circular path is fitted from the full generated column layout with its axis pinned to the boss, so depleted sectors cannot pull it inward. Orbit angle carries across mining depths. The mining camera sweeps with the orbit using smoothed, rate-limited turns and a steady orientation relative to the pile. Per-geode target queries and camera retargeting have been removed. Mining and boss combat use `Tools.setUse(true, "button")`, with the direct collector suspended independently of camp flags. Held fire releases for camp, native menus/perks, boss defeat, death, mode changes and shutdown; it resumes when native firing is allowed again. If firing makes no progress for 1.5 seconds while allowed, it reasserts the native hold to recover from silent input/focus resets. Recovery attempts are counted in diagnostics. The controller manages cash upgrades and camp visits, targets boss weak points with normal hits between openings, and resumes mining at the next depth. Camp visits and manual cracking temporarily own movement and camera. Requires an owned GEO-MAG 3000 and waits outside Endless mode. It does not cash out, escape or replay.
- **Endless Hover Clearance:** defaults to 6.5 studs (twice the older needle character clearance of 3.25), adjustable from 2 to 20 studs. Both this setting and Auto Endless save to config and teleport continuation.
- **Hide Chapter Loading Cutscene:** hides the verified local layers (`MTG_Loading`, `MTG_LoadingHud`, `MTG_Intro`) by relocating their top-level visual objects offscreen, **without changing the native `ScreenGui.Enabled` or `GuiObject.Visible` flags**. Enabled by default, reversible, and saved in config/teleport continuation. It never changes the game's `Phase` attribute or bypasses server Waiting.
- **Early Pickup During Hidden Intro (experimental):** when Auto Geode Pickup and Hide Chapter Loading Cutscene are enabled, the script may attempt one normal Pick request while the role is `Game`, phase is `Waiting`, the mound is unlocked, an owned tool is equipped and a nearby rendered geode exists. It resumes additional pickups *during Waiting* only if a matching tool response and an increase in the replicated bag count are observed before native Mining begins. If the request fails, gets no feedback, returns zero, or the game data is not ready, it stops early attempts for that intro and automatically resumes ordinary collection when the phase becomes `Mining`. Server acceptance is unproven; successful early farming is not guaranteed. The **Try Geode Pickup During Hidden Intro** toggle is on by default in Configs & Settings and is saved across teleports. `Geode/auto_pickup_diagnostics.json` includes `EarlyIntroStatus`, `EarlyAttempts`, `EarlyConfirmed` and readiness transitions.
- **3× In-Game WalkSpeed:** enabled by default while the hub runs and the game role is active. Applies three times the character's observed baseline WalkSpeed, reapplies if the game resets it, and restores the original speed on unload or leaving the game. Saves as WalkSpeedTriple in config and teleport continuation. A client-side speed change may not be honored by server movement rules.
- **Boss-first Overcharge (v1.10.14):** **Reserve Overcharge for Boss (Skip Mining Uses)** defaults **ON** in the Main tab. When **Activate GEO-MAG Ability on Boss Spawn** is enabled as well, both Auto Endless and non-Endless skill controllers deliberately refrain from automatic ability activations during Mining, keeping the cooldown ready for the Mother phase. They attempt the native `MasteryHUD.useSkill()` only once the game reports a live `Mother` phase, the skill is unlocked and equipped, and native cooldown/eligibility guards allow it. Native buff/cooldown confirmation and retry backoff remain in place. Turn reservation OFF to restore automatic Mining uses (which may exhaust cooldown before boss). Config and teleport resume persist the toggle; `auto_endless_diagnostics.json` and `non_perk_damage_diagnostics.json` show reservation and activation requests with phase. Server support for Overcharge during Mother phase has not been verified live.
- **Non-perk damage timing (v1.10.11):** the GEO-MAG's native mastery ability (called Overcharge in the hub) can now auto-activate during non-Endless Mining and at the start of the Mother boss phase. Uses the existing game's `MasteryHUD.useSkill()`, authoritative unlock/cooldown/buff state, and the game's own eligibility/confirmation. The **Auto GEO-MAG Ability in Non-Endless Mining** and **Activate GEO-MAG Ability on Boss Spawn** toggles start enabled. Managed Endless mode uses its existing ability controller, now also eligible during a live boss phase; independent controller only operates when Auto Endless is off. Actual boss-phase skill acceptance must be tested live; no guarantee of extra damage or critical hits. **Prioritize Pull Power Before Speed** defaults on and changes only the order of purchases by the existing Auto Upgrade controller when you enable it. All new preferences save in config and teleport continuation. Debug export: `Geode/non_perk_damage_diagnostics.json`. Tool attack requests/cooldowns were not altered because faster requests are not proof of faster server-confirmed damage.
- **Maximum Damage Perk Priority (experimental):** opt-in toggle in **Endless**; only affects future server-offered perks when **Auto Select Perk** is enabled. Prefers game-defined critical-hit modifiers (if any), PileDamage, BossDamage, Power, useful PickSpeed/Momentum, and offensive Overcharge abilities, with emergency oil as a safeguard. Does not edit tool damage, attack cooldowns, native firing or the server phase. The former balanced survival-oriented ranking stays the default. Saved to config and teleport resume. Export **Geode/auto_perk_diagnostics.json** to inspect `DamageFocus`, `FocusMode`, `GameDefinedCriticalPerks`, and ranked offers; no claim of guaranteed crits or faster-than-server hits.
- **Rapid Boss Input Pulses (v1.10.12, experimental):** opt-in in the Endless tab, available during native boss assist even with Auto Endless off. Calls the game's existing `Tools.setUse(true,"button")` at a configurable **0.05–0.25 second** cadence while the Magnet is already held on the active Mother boss. Default off. This is a faster input-reassertion test, **not** a direct boss RemoteEvent call and not proven to increase server attack request rate or damage. It preserves all native cooldown and eligibility checks. The Endless status panel and `Geode/auto_endless_diagnostics.json` show pulse count, observed `MotherHit` events per second, and total boss HP decrease per second; HP changes can include other players. Toggle and interval are saved across config/teleports. Compare rate with the toggle off vs on during a boss encounter; disable if performance worsens.
- **Always-On Boss Critical Assistance:** enabled by default whenever the hub is running, including when Auto Endless is disabled. Requires an owned GEO-MAG 3000 in a live Mother boss phase. Uses normal native held fire and camera/movement targeting, prioritizes replicated exposed weak spots with remaining hits, and falls back to ordinary boss hits when no critical spot is exposed. The **Auto Boss Critical Hits (Always On)** toggle in Endless controls it, saves to config and persists through teleport. This does not guarantee that every hit is critical because weak points must be active and the server verifies hits. The v1.10.4 fix initializes the character when Auto Endless is off and samples weak-point state every 0.04s; only exposed, server-recognized points can receive critical hits.
- **Automatic Q / Overcharge:** included in Auto Endless. Uses the native `MasteryHUD.useSkill()` function only during active mining with the equipped, unlocked GEO-MAG ability. It pauses for boss combat, camp, menus and perk selection. Activations are confirmed by replicated buff/cooldown state; manual Q cooldowns are respected and unconfirmed attempts back off. Base Overcharge is a five-second buff with 3x pull radius and 2x pull rate, on a 45-second cooldown; native mastery/perk stats supply the effective values. Ability status and confirmed uses are shown in the Endless tab and diagnostics. A live activation was confirmed with an active Overcharge buff and a replicated ready timestamp.
- **Auto Select Perk:** ranks Endless offers for a GEO-MAG-only run and uses the native card-pick function once the cards are ready. It handles offers already open when enabled, scores actual rarity/stack counts, and confirms choices through server events or replicated perk counts. It sends one selection per offer and does not reroll. This separate toggle defaults off and saves to config and teleport continuation.
- **Auto Geode Pickup:** selects valid nearby mound targets, uses the equipped owned tool, respects its calculated cooldown and a configurable range up to 26 studs. Pet feedback is excluded from tool confirmation counts. The pickup diagnostics file now refreshes every 3 seconds while enabled, even when there are zero requests, and records state transitions and current replicated role/phase, mound lock, rendering readiness and tool state. An export written milliseconds after loading may still show Lobby and no mining phase.
- **Escape results Play Again fix (v1.10.19):** corrected the replay handler for the **YOU ESCAPED!** summary with its green **PLAY AGAIN** button and short **BACK TO CAMP** countdown. The controller now recognizes separately rendered TextLabels and image-backed buttons using their actual visible positions, prioritizes the results UI before Lobby/Phase transitions, checks the replay screen about every 0.055 seconds, and retries input within the brief countdown. It rotates through supported input methods (VirtualInputManager, executor `firesignal` when attached to an actual GuiButton, and VirtualUser) without inventing replay remotes. Results UI scans are paused during active Mining for efficiency. `Geode/auto_farm_escapes_diagnostics.json` now reports `MatchingButtons`, `ResultPanelVisible`, `LastClickMethod`, and available click backends. **The fix is code-verified but still needs a live result-screen test; a simulated click event is not confirmation of replay acceptance.**
- **Auto Farm Escapes (v1.10.18, experimental):** optional **Main → Auto Farm Escapes (Play Again Loop)** toggle, off by default. When a standard (non-Endless) round reaches Mining, the loop equips the owned GEO-MAG 3000, starts geode collection, activates the existing one-time Crack & Sell flow with a **1-second wait after the first bag-count change**, and maintains a separate **five-height, 5× circular sweep** to clear the rest of the mound after returning to the saved position. It reuses native held-fire boss weak-point targeting when the Mother phase appears, and the existing Auto Escape lift controller when the Escape phase begins. Only the replicated `Escaped` flag counts as a successful escape. At that point the loop stops collection and looks for a visible native **Play Again / Replay** button, clicking via supported simulated input; if the game returns to a lobby, it can also click an exact **Play / Solo** button to rejoin. Clicks are rate-limited (at least 6 seconds between requests) and limited to five per replay/lobby stage. Starting the loop enables the existing **Queue on Teleport** feature if necessary; it restores the loop on eligible game teleports using the personal BeyyHub loader. Running Auto Farm Escapes disables Auto Endless; it does not alter Auto Endless's normal behavior when the escape loop is off. The one-time camp visit requires the game's Crack All entitlement/credits, and full automation requires GEO-MAG 3000 ownership. If the bag fills again after the only sale, the sweep pauses and reports the capacity problem rather than silently making another unauthorized turn-in; sufficient or unlimited bag capacity is needed for an uninterrupted full mound clear. If the turn-in fails, the escape loop stops rather than pretending it succeeded. Saved config and teleport state include this toggle. Export `Geode/auto_farm_escapes_diagnostics.json` for rounds, status, clicks, visible buttons and errors. **The exact replay UI and uninterrupted multi-round loop have not yet been confirmed in-game**; scripted clicks can depend on executor support and the game's UI. This feature is a best-effort integration, not a verified infinite farm.
- **Auto Crack and Sell (one trip by default):** starts a 1-second window after the first bag-count change (editable in the Main tab). It suspends collection, deposits, enters a free station, uses Crack All, leaves, sells and returns to the original pickup position. After the first successful complete cycle it disables itself so further pickups cannot trigger repeat camp visits. Manually enabling it again starts a fresh single cycle. **Keep Cracking & Selling** overrides one-shot behavior to repeat cycles at the configured delay. A fresh bag change starts the next window.
- **Auto Crack & Sell reliability fix (v1.10.20):** repairs failure paths introduced by the fast camp route and one-trip escape farming. Landing positions are now clamped within actual native proximity prompt range before moving. Deposit, station entry and sale prompts can recover from ignored requests (at most two retries per stage) rather than immediately timing out; camp travel settle is 0.18–0.20s for replication reliability. Deposit completion now waits for replicated station crates or sale-bin contents, and Crack All waits for confirmed bin contents before leaving. Sale completes only after replicated cash growth or a confirmed `Sold` event; a timer alone no longer marks the one-time turn-in successful. Server-response stages are armed before issuing prompts to avoid missing fast acknowledgements. No additional paid Crack All requests are sent automatically. The one-second initial bag-change delay and one-trip safeguard remain unchanged. `Geode/auto_crack_sell_diagnostics.json` now includes prompt retries, failure stage, confirmed-sale status and stage timings, also surfaced in the Main UI. This fix is code-verified; real-server timing still requires a live test.
- **Fast Crack & Sell Teleport Route (v1.10.15):** on by default in Main > Cracking & Selling. Each post-teleport prompt settle changes from 0.15s to 0.10s; active-stage polling changes from 0.03s to 0.02s; the sale-balance settle fallback changes from 0.20s to 0.10s, while immediate cash confirmation still completes sooner. The route evaluates verified prompt activation ranges at runtime to reuse positions reachable from multiple camp interactions, reducing unnecessary camp teleports when geometry permits. It never omits deposit, station entry, server-confirmed Crack All, leave or sale steps; the return to the original pickup position and the one-trip safeguard are unchanged. The initial bag-change delay remains **1 second**. The toggle can be disabled to use the original timings/route. Config and teleport resume preserve it. The Crack & Sell status displays measured last-trip time and the number of camp teleports saved; the JSON diagnostic includes these and per-stage elapsed times. Faster completion depends on server confirmation/replication and has not been live-verified yet.
- **Auto Upgrade GEO-MAG 3000:** buys only Pull Power and Pulse Speed with run cash, checks affordability and replicated levels, and waits during camp cycles.
- **Class Mutations:** dedicated tab with owned-class selector, Normal/Lucky Scroll selection, target mutation and a 1–1000 roll limit per start (default 10). Rolls sequentially through the native Mutations remote without the animation, respecting the native minimum request interval. Stops at the target or higher, the request limit, no scrolls, unowned class, or a failed response. Keeps the better mutation through server logic. Parameters save to config; rolling starts off after reloading and is not resumed by teleport. Changing parameters applies on the next start. An in-flight request may finish after Stop; no additional requests follow.

Station exit advances immediately once confirmed, and sale settlement can finish as soon as the cash update arrives. Active cycles poll at 30 ms; idle polling remains 100 ms. Collection/repeat delays remain configurable and unchanged.
- **Upgrade completion:** When the owned GEO-MAG has both upgrade tracks at their replicated maximum levels, Auto Crack and Sell finishes a final collection/sale and returns to the pickup position before turning off. Existing bag, crate and bin contents are processed even without another bag-count change. An empty inventory requires no final trip. This also works when Auto Upgrade is off. Enable **Keep Cracking & Selling** for intentional repeated trips even after max upgrades. The Repeat Crack & Sell Delay slider sets 1–60 seconds between completed cycles (default 10 seconds), skips empty trips, and saves to config/teleport continuation.
- **Auto Escape:** waits for Escape phase and LiftOpen, then finds the current CaveMap lift and moves above its floor, adapting to each chapter. It preserves facing direction, stops camp movement first, waits for the server's Escaped flag, and retries only if displaced (up to ten moves per character/round). The toggle saves to config and teleport continuation.
- **Auto Open Haunted Egg:** opens three per request, using the current candy price (180 at inspection). Requests are sequential; Busy replies back off. It waits for sufficient candy and stops on event expiry or other errors.
- **Anti AFK (v1.10.16):** defaults ON in **Configs & Settings → AFK Protection** and remains active in both the lobby and all game phases, regardless of which farming features are enabled. Uses the client's `LocalPlayer.Idled` event and `VirtualUser` to send a brief paired virtual right-mouse input when idle, plus a 15-second watchdog that can repeat the input after 90 seconds without actual user input (with at least 75 seconds between attempts). It does not move the character, change the camera CFrame or modify gameplay remotes. It cleans up events and timers on hub unload, and remembers its toggle in the saved config and teleport continuation. A live **Anti AFK Status** and **Export Anti AFK Diagnostics** button report attempts and failures (`Geode/anti_afk_diagnostics.json`). Anti-idle cannot guarantee against server shutdowns, internet disconnections, executor suspension, or server-side kicks unrelated to idle detection.
- **Queue on Teleport:** reloads this hub after real Roblox teleports, with cached fallback and recent enabled settings. Its online fallback also uses BeyyHub's `geode-mirror/loader-beyy.lua` instead of an upstream loader, so the Auto Farm Escapes setting is retained on supported destination places within the same Roblox game universe.

## Loader and cache recovery

Loader v2 rejects empty downloads, incomplete content, missing hub markers, and compile failures before replacing a cache. It maintains a validated `GeodeHub/main.backup.lua` and reports startup errors.

This fixes a confirmed issue where an HTTP request returned success with an empty body: empty Lua compiled, overwrote the cache, and silently did nothing.

### GEO-MAG perk priorities

These are heuristic priorities for reaching more Endless depths, rather than a guaranteed optimum. Shortcut, recurring Oil Flask sustain, Eternal Flame and Wide Sweep are high priorities. Pile damage, Chain Reaction and boss damage follow, with rarity/stack count and existing modifiers affecting their order. Emergency oil takes priority when less than a minute of effective burn time remains. Extra recurring oil is downgraded when the existing income covers the recently measured depth pace.

Speed perks use the active firing path's estimated timing floor: measured frame timing during Auto Endless native held fire, or the direct pickup loop's 50 ms floor otherwise. Bag perks are downgraded with unlimited capacity. Crack-power bonuses are evaluated through the boss damage square-root curve. Cash/value is more useful before GEO-MAG upgrades are maxed. Ability duration, cooldown, size and damage perks gain priority when automatic Overcharge is unlocked and active; ability cooldown perks are downgraded at the configured cooldown minimum. The ranking export includes the current order and the actual reasoning for each offered card.

The native selection path was checked live: an Epic Tempered card was selected over Gem Finder and Bottomless Luck and confirmed by the server. No rerolls were used.

The whole-pile scan measured five contour radii of approximately 33.5, 28.0, 21.9, 15.6 and 9.8 studs. Auto Endless now uses only the bottom contour (about 33.5 studs in that snapshot). Radius varies with angle, depth shape and depletion. The character path sits above the fitted slice by the configured hover clearance. Geometry tests covered all 1,577 columns in a live snapshot, with 13,387 generated blueprint cell locations and 3,785 deduplicated visible targets. Blueprint positions include already-mined cells; runtime planning uses remaining stack counts.

## Passive transition recorder

A separate observer records PlaceId, JobId, OnTeleport events, phase/run-start changes, and queued arrivals. It makes no gameplay requests.

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/sceneton/geode/main/transition-recorder.lua?refresh=" .. tostring(os.time())))()
```

Logs: `Geode/transition_events.jsonl` and `Geode/transition_latest.json`.

Stop it with:

```lua
getgenv().GeodeTransitionRecorder.Stop()
```

A changed JobId establishes a server change. A changed RunStart in the same surviving observer/job indicates an in-server run reset. Compare the actual Play Again transition; a custom loading screen alone does not distinguish the two.

## Validation and limits

The pickup loop and camp sequence were exercised live. Egg single-triple and overlapping-triple requests were tested with permission; simultaneous requests received Busy rejections. Scheduling, candy limits, upgrades, cleanup, bag-change timing, queue lifecycle and loader recovery have focused local tests. Some controller integrations still need ordinary live observation.

The raw game dump, player state, and diagnostic logs are kept local and are not included in this repository.
